# reverentgeek/tap

Homebrew formulae for [SiteSquatch](https://github.com/reverentgeek/sitesquatch) (`ssqch`), a static site generator.

```sh
brew install reverentgeek/tap/ssqch
```

The formulae in `Formula/` are written by SiteSquatch's release workflow, so don't edit them by hand: changes are overwritten by the next release.
